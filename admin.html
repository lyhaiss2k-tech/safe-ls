Hướng dẫn kết nối tự động lưu vào Google Sheets (Chỉ mất 2 phút)

  1. Mở một file Google Trang tính (Google Sheets) mới trên Google Drive của cô giáo.
  2. Trên thanh menu của Google Sheets, bấm: Tiện ích mở rộng (Extensions) $\rightarrow$ Apps Script.
  3. Xóa hết mã có sẵn trong Apps Script và dán đoạn mã ngắn gọn bên dưới vào:
function doPost(e) { var ss = SpreadsheetApp.getActiveSpreadsheet(); var data = JSON.parse(e.postData.contents); // 1. Phân loại trang tính riêng biệt cho Giáo viên và Học sinh var targetSheetName = (data.role && data.role.indexOf("Giáo viên") !== -1) ? "Giáo viên" : "Học sinh"; var sheet = ss.getSheetByName(targetSheetName); // Tự động tạo trang tính mới nếu chưa có if (!sheet) { sheet = ss.insertSheet(targetSheetName); } // 2. Tự động tạo hàng tiêu đề nếu là lần đầu tiên trang tính được tạo if (sheet.getLastRow() === 0) { sheet.appendRow([ "Thời gian", "Đối tượng", "Họ tên", "Trường/Lớp", "Điểm số", "Phần trăm", "Xếp loại", "1. Nhận diện DLCN", "2. Bảo vệ tài khoản", "3. Lừa đảo", "4. Quyền riêng tư", "5. AI an toàn", "6. Xử lý sự cố" ]); } // 3. Ghi kết quả mới vào đúng trang tính tương ứng sheet.appendRow([ data.timestamp, data.role, data.name, data.organization, data.score, data.percentage + "%", data.level, data.skill1, data.skill2, data.skill3, data.skill4, data.skill5, data.skill6 ]); return ContentService.createTextOutput(JSON.stringify({result: "success"})) .setMimeType(ContentService.MimeType.JSON); }

  2. Chọn loại: Ứng dụng web (Web app) $\rightarrow$ Mục Ai có quyền truy cập (Who has access): Chọn Bất kỳ ai (Anyone) $\rightarrow$ Bấm Triển khai.
